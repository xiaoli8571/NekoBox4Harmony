## 2. 待应用（草稿→应用）机制（P4/W16 已交付）

- 运行配置（DNS、模式、IPv6、嗅探、MTU、入站、分应用名单、Clash API 等）**不再"改了就生效"**：修改先进草稿，页面顶部出现「有 N 项修改待应用」，点应用才提交一次应用事务。
- 应用事务：保存新快照 → 运行中时扩展校验快照与本地设置一致 → 串行重启内核一次 → 回执 `operationId + appliedRevision`，UI 收到匹配回执才显示已生效。**离线时只保存，标记"下次连接生效"，不假装已生效。**
- 放弃草稿可恢复为运行中的设置值。
- 即时效项（外观、列表密度、地址显示、通知分组、排序等）不进入该流程。
- 失败行为：快照缺失/校验失败 → `snapshot_unavailable`；本地设置未写入快照 → `settings_out_of_sync:<key>`（不重启）；重启失败 → `apply_failed`，待应用保留并显示原因，不无限重试。

## 3. 组播拒绝语义修正（P4/W14，§7.4/C7）

- 旧：`ip_cidr` 与 `source_ip_cidr` 写在同一普通规则里 → sing-box **同规则不同字段是 AND**，即"目的组播 **且** 源组播"，实际几乎永不匹配（组播流量未被拒绝）。
- 新：`{type:'logical', mode:'or', rules:[{ip_cidr:[224.0.0.0/3, ff00::/8]},{source_ip_cidr:[…]}], action:'reject'}` —— 源**或**目的命中组播段即拒绝。
- 地址范围**未缩小**：仍是 `224.0.0.0/3`（含部分保留地址）+ `ff00::/8`；如需改为 `224.0.0.0/4` 属独立策略变化，另行评估。
- 证据：`tests/parity-config.cjs` 已按新语义断言（40 checks PASS）；真机匹配验证待设备。

## 4. 检测（Probe）相关（P2 已交付）

- 整批 URL Test 启动失败**不再静默整批回退 TCPing**（C3）：按二分隔离定位问题节点，其余节点仍按原方法检测；TCP 回退仅限逐节点显式开关。
- HTTP 判据：**新装机默认 2xx**（C4，防 CDN/GFW 劫持返回 403/500 被判绿）；老装机保留原 `any` 语义不迁移。
- 检测结果落独立存储（`files/probe/probe-results-v1.json`），带 profile/configHash/方法/目标/策略/路径复合键；结果为陈旧时灰色显示而不是沿用旧颜色。

## 5. 分应用名单（P1/P4 已交付）

- `include` 空名单**阻止连接/应用**并提示至少选择一个应用（C9），不再"名单为空就静默全应用"。
- 上限按系统 API：API≥23 为 256，API<23 为 64；超限阻止并定位，不静默截断。
- 历史数据中的 include 空名单在升级时记录风险，要求修正后再应用；运行中的旧会话不被迁移线程改策略。

## 6. 旧「按包名指定出站」规则（P4/W14，§8.5）

- 编辑器移除"包名指定出站"控件，改为平台限制说明 + 分应用入口。
- 历史含 `packages` 的规则标 `unsupportedOnPlatform`，**原文与旧启用状态保留**，归入"需处理的旧规则"；应用前必须显式选择：保留暂停 / 改为支持的域名·IP 条件 / 删除。
- **不会**自动把"某应用走香港节点"转换成"该应用进入 VPN"——语义不同。

## 7. 订阅三层模型与更新事务（P5/W17 已交付）

- 订阅数据分三层：**原始层**（每次更新留当前+上一份快照文件，永不覆盖）、**覆盖层**（别名/收藏/排序/展示分组/传输字段覆盖 + 墓碑，唯一持久化位置为配置快照 `content.userOverrides`）、**有效视图**（两者合并）。
- **远端改名不再表现为"加一个删一个"**：节点身份 = 订阅 URL + 传输特征指纹（**显示名不参与**）。远端只改名字 ⇒ 同一节点，id/收藏/排序/累计流量全保留。
- 反向取舍（如实告知）：服务器地址变化（含 forceResolve 解析结果变化、动态 DNS 换 IP）会改变身份指纹，表现为加+删——与 Android 按名合并的取舍不同。
- 覆盖冲突不猜测：身份对不上但源名称唯一对应 → 视为"参数变更"，覆盖迁移、用户传输覆盖记冲突不自动套；同名多对一 → 按加+删处理。
- **304 语义收窄**：订阅服务器返回 304 时只推进"上次更新时间/下次更新时间"，节点、覆盖层、原始层**一律不动**（旧版会把 304 当普通成功重写数据）。
- 更新失败写 `lastError/lastAttemptAt` 并在订阅行原样展示（展开可见原文，不吞错误）；「更新全部」逐订阅出结果行，一个失败不覆盖其他订阅的结果。
- 订阅详情页新增**墓碑区**：远端已删除的节点列出，可显式「转为手动节点」（从原始层还原传输字段，覆盖随迁；找不到原始记录则拒绝，不凭空捏造）。
- 「清空节点」与「删除订阅」分离：清空只删节点保留订阅记录，可再次更新找回。

## 8. 日志与流量统计（P5/W20 已交付）

- **清除日志真实生效**：清除 = 记录"文件偏移 + 文件身份"标记；页面重建、应用重启后旧日志不重现，新日志仍可见（旧版重建后旧日志全部回来）。
- **导出日志默认脱敏**：URL 凭据、订阅 token、密码、分享链接 base64 载荷自动打码，导出前有预览；「导出原文」是显式红色次要按钮（用户主动选择才导出明文）。
- **清除流量统计改基准语义**：清除 = 记录基准偏移，显示值 = 当前 − 基准；修复旧版"清除后被 1s 轮询写回旧值"。内核重启（计数器小于基准）时基准作废、显示原始值，不出负数。
- 已知降级：通知栏流量基准在会话启动时同步一次，UI 会话中途清除后通知最迟在下一次会话/应用后同基准。
- 诊断包（工具页「生成诊断包」）：固定键序 JSON，不含节点密钥与订阅 URL，不自动上传。

## 9. 连接页（P5/W19 已交付）

- 连接列表只展示内核真实证据：目标（域名>IP）、开始时间、上下行、内核规则表达式原文、策略链。
- 点击连接行弹「为什么走这条线路」：目标→内核规则原文→规则载荷（**内核未提供就显示"未提供"，不伪造**）→策略组链→最终节点+运行 revision+采集时间。
